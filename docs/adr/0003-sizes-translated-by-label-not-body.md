# Sizes translated by label, not by body measurements

Each Retailer's Size label is mapped onto one UK size (EU 50, US 18, 3X and "22/24" become UK 22), so a Shopper's size works across every Retailer from launch. Matching on body measurements from each Retailer's size chart would fit better, since a 22 at one Retailer can fit like a 20 at another, but it needs every chart collected and maintained. We start with labels and may move to measurements later.
