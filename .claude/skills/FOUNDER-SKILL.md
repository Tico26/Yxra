# Founder skill pack

The eleven `founder-*` skills here are copied unchanged from
[Jakeschincariol/founder-skill](https://github.com/Jakeschincariol/founder-skill)
at commit `fd9385b` (v1.0, MIT, see `FOUNDER-SKILL-LICENSE`).

Run them in this order; each reads what the others wrote in `founder/`:

```
board -> competitors -> consumer -> pricing -> offer -> cfo -> marketing -> brand -> ops -> launch -> plan
```

The Python tools need Python 3.8+ and nothing else. To update, copy the
`skills/founder-*` folders from a newer commit over these.
